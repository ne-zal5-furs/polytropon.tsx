# fullstack-dashboard

Standalone physics simulator for browser from builder.py 4 for usage outside of builder.py.

Can be used with monitor, themes apps, and modern frameworks.

## Usage

Install using package manager: npm install fullstack-dashboard

Include in your project: import { fullstack-dashboard } from 'fullstack-dashboard';

Alternatively, include dist/fullstack-dashboard.js in your project.

Documentation available in the builder.py repository.

## Example

A simple example app is provided in examples directory.

## Updating

You can update and recompile by running update script.
